# 3DBrailleSignMaker

Gerador online de placas acessíveis em **Braille para impressão 3D**, com suporte a texto em alfabeto latino, personalização das dimensões das placas e inclusão opcional de símbolo NFC para audiodescrição.

## Sobre o projeto

O **3DBrailleSignMaker** é um software livre e gratuito, desenvolvido a partir de projetos de código aberto (*open-source*) anteriores voltados à geração de placas em Braille para impressão 3D.

Esta versão constitui um trabalho derivado, amplamente modificado e expandido, que incorpora **novas funcionalidades de acessibilidade**, melhorias substanciais de interface, reorganização estrutural e adaptações para uso institucional e educacional.

O desenvolvimento integra as atividades do **Laboratório de Acessibilidade e Ações Inclusivas (LAAI)**, do Instituto Federal de Educação, Ciência e Tecnologia do Rio Grande do Sul (IFRS) – Campus Caxias do Sul.

## Principais recursos

- **Texto latino e Braille:** geração simultânea de inscrições nos dois sistemas de escrita.
- **Dimensões personalizáveis:** ajuste do tamanho das placas conforme as necessidades de aplicação.
- **Símbolo NFC:** inclusão opcional de identificação para recursos de audiodescrição.
- **Interface organizada:** distribuição das funcionalidades em blocos para facilitar a utilização.
- **Impressão 3D:** ajustes de parâmetros para fabricação das placas.
- **Suporte ao português:** aprimoramentos na geração de textos em português e sua representação em Braille.
- **Aplicações institucionais:** layout pensado para escolas, campi e outras instituições públicas.
